# IJ Technologys

A single-page marketing site for **IJ Technologys** — a web studio building websites, online shops and custom digital products.

Built as a self-contained `index` HTML page with:

- **Three.js** WebGL scenes — drifting particle background, a liquid-metal shader hero card, and a code-core tech globe with orbiting project cards
- Scroll-driven animations, an animated CSS "developer at the desk" illustration
- Bilingual UI (English / Albanian) with a language toggle
- Fully responsive, respects `prefers-reduced-motion`

## Run locally

Just open the HTML file in a browser:

```
ij-technologys-pro.html
```

No build step required. Fonts (Google Fonts) and Three.js load from CDNs.
